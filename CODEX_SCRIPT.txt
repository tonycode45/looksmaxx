# GOAL

Create a privacy-first React Native (Expo) mobile app called "MirrorMe" that runs on-device face analysis to generate daily looksmax tips, tracks progress, and composes a weekly timelapse. Follow the repo files below and implement production-ready code with clear separation of concerns.

# TECH

- Expo (React Native), TypeScript, Expo Router

- Zustand for state, Expo SQLite for local storage

- Expo Camera + MediaPipe/TFLite (face landmarks)

- React Native Reanimated for micro-interactions

- No backend; no network calls

# FOLDERS

app/
  _layout.tsx (tabs: Home, Progress, Settings)
  index.tsx (Home: Scan + Score + Today's Actions)
  progress.tsx (calendar, gallery, timelapse compose)
  settings.tsx (privacy, export, delete)

components/
  ScoreRing.tsx, ActionCard.tsx, Badge.tsx

ml/
  landmark.ts (camera stream → landmarks)
  scoring.ts (compute subscores + overall)
  tips.ts (map subscores → 3 actions)

state/
  useStore.ts (scans, actions, badges)
  db.ts (SQLite schema & CRUD per DATA_MODEL.md)

config/
  flags.ts, theme.ts

utils/
  media.ts (capture, align framing), timelapse.ts (compose from frames)

# REQUIREMENTS

1. **Onboarding/Consent** modal on first launch, persisted to SQLite

2. **Live Scan** screen: camera preview, Start button, 2-second analysis, show score & subscores

3. **Today's Actions**: pick 3 from tips engine; mark done/undo; store in plan_items

4. **Progress**: grid of dated scans; Play Timelapse (compose mp4 locally)

5. **Badges/Streaks**: award after N consecutive completions

6. **Settings**: Export JSON+media zip; Delete all data; toggle Reduce Motion, High Contrast

7. **Accessibility**: labels, large hit areas

8. **Privacy**: no outbound network, all storage local

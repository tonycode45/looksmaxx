# UI Styleguide

## Brand

- Vibe: futuristic, encouraging (not clinical)

- Palette: background #0B0F14, primary #64D2FF, accent #A78BFA, success #34D399, warning #F59E0B

- Typography: Inter (system fallbacks), weights 400/600/800

- Radii: 16–24, Shadows: soft

## Components

- **ScoreRing**: animated circular progress, 0–100

- **ActionCard**: title, why-it-helps, estimate, start button

- **Badge**: level, earned date

## Motion

- Use Reanimated for subtle scale/opacity on press.

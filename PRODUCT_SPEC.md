# Product Spec

## Problem

People want practical, daily, visual feedback to improve looks (posture, skin, grooming) without creepy data collection.

## Solution

On-device scan → score + 3 daily actions → weekly timelapse → badges. Shareable but private by default.

## Personas

- **Grinder (17–24):** gym + looksmax, wants dopamine hits and progress pics.

- **Glow-up (16–22):** skincare + hair, wants friendly guidance.

## Core Loop

Scan → Get Score (0–100) → Accept 3 actions → Complete → Streak/Badge → Repeat.

## Success Metrics

- D1/D7 retention

- Weekly scans/user

- Action completion rate

- Timelapse exports

## Non-Goals

- No remote diagnosis or medical claims.

- No cloud-only features in v1.

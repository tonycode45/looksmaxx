# User Stories

### MVP

- As a user, I can opt-in to camera analysis with clear consent.

- As a user, I can run a live scan and view a score with 3 prioritized actions.

- As a user, I can capture a guided selfie (same framing) for progress.

- As a user, I can view a weekly timelapse.

- As a user, I can earn badges for streaks and milestones.

- As a user, I can export/delete all data locally.

### Nice-to-have

- Community themes (e.g., Jawline Month, Skin Week).

- AR try-on for hair volume/beard.
